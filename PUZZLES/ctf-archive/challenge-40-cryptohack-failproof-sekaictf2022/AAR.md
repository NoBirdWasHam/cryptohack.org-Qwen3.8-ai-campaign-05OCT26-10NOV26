## Scheme
- secret = urandom(16) printed on connect; pubkey A = 128 chained sha256 states (256-bit ints).
- c_j = popcount(A_j & m) per 32-byte block => integer (not mod-2) system A_bits·m_bits = c over
  binary unknowns; ASCII => byte MSBs = 0. Live capture: live_output.txt (secret + 3 c-vectors).

## Root causes of prior failures (found this session)
1. kern321.gp solved A_keep·x = c_raw for b0 while keeping the assumed "crypto{" prefix columns
   OUT — true RHS is c − A_fix·prefixbits (old m0: maxerr 0 vs raw c, 23 vs corrected RHS) =>
   wrong coset, no short vector ever existed there.
2. THE FLAG STARTS WITH SEKAI{ (SekaiCTF format), NOT crypto{. Any forced-prefix assumption makes
   the b0 coset provably empty (qfminim N=0). Fix: solve b0 with NO prefix assumption (drop only
   byte MSBs, like block 1) and let the bytes speak.
3. Reconstruction bug (also in the old fpylll solve321_kannan.py): after Babai-reducing
   T0 -> Tred = T0 − x (x ∈ 2L), candidates must decode with the ORIGINAL T0:
   m = m0p + (T0 − pt)/2. Using Tred adds a lattice offset => non-binary m even when enumeration
   returned the true point. A known-block TOY round-trip localized this (Tred norm² was exactly
   224 = solution present, yet decode failed). Toy variant retained in the generator.
4. Old fpylll script also: enumerate radius passed as 705 = NORM not norm², plus gso.get_r index
   crash; fpylll itself is no longer installed on this host (only unpacked sdist in %TEMP%).

## PARI 2.17 API pitfalls (all observed on gp64 2.17.4)
- errcatch REMOVED ("not a function in function call").
- qfminim returns [N, maxnorm^2, Mat] with vector columns (± collapsed) = COEFFICIENT vectors
  w.r.t. the Gram basis; a bound exactly equal to lambda can MISS the vector (float radius) —
  pad the bound.
- qflll on non-square bases has confusing orientation; robust recipe:
  U = qflllgram(B·Bᵀ, 1); Bred = U·B.
- Mat(vec-of-vecs) builds a matrix OF VECTORS; use matrix(rows,cols,r,c,expr).
- File parser: statements must be single-line (no backslash continuation); multi-line only
  inside a function-definition body; nested function definitions inside a body => "embedded
  braces (in parser)" error => define helpers at top level and wrap the main flow in fn().
- Vec() of a matrix = column list; transposes: t_COL~ = t_ROW; prefer
  vecsum(vector(n,j,a[j]*b[j])) dot products over a~*b.
- String literals interpret backslash escapes — use forward slashes in paths.

## Vulnerability (plain words)
The scheme publishes 128 vectors `A_j` (chained sha256 states, 256-bit) and answers `popcount(A_j & m)` — an *integer* count, not a mod-2 parity. Those counts are exactly a dense linear system `A_bits * m_bits = c` over the binary unknowns of the flag, with fully known coefficients. ASCII zeroes every byte's MSB, so the binary solution is nearly unique and a closest-vector search turns the linear algebra into the flag.

## How the answer follows
1. Per 32-byte block: coefficient matrix = bits of the 128 `A_j`, unknown = block bits (+ byte-MSB==0 equations), RHS = the 128 observed popcounts **with known-prefix contributions subtracted** (`c - A_fix * prefixbits`) — this glue fix was the decisive blocker; solving against the raw c puts you in a provably empty coset (qfminim N=0 evidence).
2. Tail block (18 zero bytes of the 78-char flag): unique solution by exact rational linear solve (`tail321.gp`, b2_tail.txt).
3. Blocks 0/1 via PARI/GP 2.17 Kannan-CVP (`gen_gp321b.py` -> run321_b0free.gp / run321_mid2.gp): `matsnf(A2,1)` gives kernel K + particular m0p; `T0 = 1 - 2*m0p`; exact-Fraction Babai nearest-plane on the reduced `B = qflllgram(2K*2K^T,1)*2K`; Kannan embedding rows `[(Bred|0); (Tred|1)]`, beta=1 => target norm^2 = n+1, search bound n+9; `qfminim` returns N=2 (a single +/- pair); decode `m = m0p + (T0 - pt)/2` **with the ORIGINAL T0** (using Tred adds a lattice offset and yields non-binary m even when the true point was enumerated — localized with a known-block TOY round-trip whose Tred norm^2 was exactly 224).
4. Density checks: dim 97, density ~0.70-0.73, LLL-only basis sufficed (gap ~20), ~3 min/block single-threaded (SNF dominates). Every byte re-verified against all 128 popcount equations vs the live-published A, then submitted: `[flag — recorded in FLAGS/ctf-archive/challenge-40-cryptohack-failproof-sekaictf2022/flag.txt]` (78 chars = 32+32+14).
