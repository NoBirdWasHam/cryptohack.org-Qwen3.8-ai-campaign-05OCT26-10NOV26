## Statement (paraphrased from remaining_descs.json)
CSIDH works with supersingular curves over F_p (p ≡ 3 mod 4), where
E(F_p) = Z/(p+1) and there is a unique order-ℓ subgroup generating an ℓ-isogeny.
For now assume all isogenies are generated by rational points P of order ℓ on E/F_p.

Take the curve E₀ : y² = x³ + x (mod 419). Compute a point of order 5, use it to
compute a degree-5 isogeny, and look at the curve equation. Repeat with another
point of order 5. What do you observe?

**Flag: the Montgomery coefficient A of the codomain of the degree-5 isogeny**
(codomain in Montgomery model y² = x³ + A x² + x).

## Parameters
- Domain E₀: y² = x³ + x mod 419. #E₀ = 420 = 2²·3·5·7. j(E₀) = 1728 (supersingular).
- Only ONE F_419-rational 5-torsion subgroup: ⟨(185,73)⟩. Its four nonzero points:
  (185,73), (349,133), (349,286), (185,346). (The "what do you observe?" answer:
  both choices give the SAME codomain, since the same subgroup is generated.)
- p = 419 (p ≡ 3 mod 4, F_p sqrt via pow(v,(p+1)//4,p)).

## Answer
- Vélu degree-5 isogeny (PARI `ellisogeny`) codomain: **y² = x³ + 269x + 82** (j = 13, #E′ = 420).
- Montgomery conversion → **A = 199**.

## Montgomery conversion (the actual trick)
For a short-Weierstrass y² = x³ + a x + b with a rational 2-torsion x-root v:
1. Shift x = X + v  →  y² = X³ + 3v X² + (3v² + a) X.
2. Scale X = u² X′, Y = u³ Y′ with u⁴ = (3v² + a)  →  y² = X′³ + (3v/u²) X′² + X′.
3. **A = 3v / u²** where u² = √(3v² + a).

For our curve: v = 23, 3v²+a = 180, u² = √180 = 173, A = 69/173 mod 419 = **199**.

**Twist disambiguation**: the j-mate A′ = 220 is the quadratic twist. Verify by
applying the explicit isomorphism to actual points: 210/210 codomain points land on
y² = x³ + 199x² + x, but only 1/210 land on the A = 220 curve.
