## Problem
statement.txt: "novel encryption protocol... compression". Provided source.sage: p = 37·2⁶⁴·lcm(1..255) − 1, E/F_{p²}: y² = x³ + 1 (i² = −1), #E = (p+1)², two public points P, Q. For each flag byte b: pick random s < 2⁶⁴·b, form kernel ⟨((p+1)/(2⁶⁴·b))·(P + sQ)⟩ — a cyclic group of order **2⁶⁴·b** — compute φ = isogeny with that kernel, output φ(P), φ(Q). Ciphertext = 52 such point pairs (one per flag byte).

## Attack / Derivation (as implemented in solve.gp, the final script)
Per ciphertext byte (52 iterations over DATA from bytes.gp, generated by gen_gp.py from output.txt):
1. Reconstruct the codomain curve: over F_{p²} = ffinit(PVAL,2) with I2 = sqrt(−1) (Tonelli–Shanks `ffsqrt_ts`, verified `i^2+1 == 0: 1` in full_out3.txt), fit `y² = x³ + a4x + a6` through A=(Ax,Ay), B=(Bx,By): `a4=(RA−RB)/(Ax−Bx)`, `a6=RA−a4·Ax`; check both points on curve (`ellisoncurve`).
2. For each prime power lᵉ ‖ (p+1) (prime/ exponent lists PR, EE from params.gp), scale both points by MVAL/lᵉ where MVAL = p+1, landing in the lᵉ-torsion direction: `Ae=[M/lᵉ]A`, `Be=[M/lᵉ]B`; compute the Weil pairing `zpl = ellweilpairing(E,Ae,Be,l^e)` and find its order l^vv by testing `zpl^{l^k}==1`.
3. `vl = e − vv` is the l-adic valuation of the kernel order: the isogeny of degree containing l^{vl} kills exactly that much of the pairing (pairing degenerates by the kernel). Special case `l=2: vl = 7 − vv` (the fixed 2⁶⁴ factor; e=7).
4. The byte is `b = ∏ l^{vl}` over all l (valid since b ≤ 255 < every lᵉ's saturation, and the kernel order was 2⁶⁴·b), emitted via `Strchr(b)` and concatenated.

full_out3.txt shows the complete run: 52 derived characters spelling the flag, exit 0.

## Learning points
- Weil pairing + isogeny = order detector: e_l(φ([n]P),φ([n]Q)) loses exactly the kernel's l-part, so pairing order deficits read out the hidden kernel valuation — here encoding a byte.
- Reconstructing curve coefficients from two points is trivial (2 linear conditions on a4,a6); "encryption" that ships images of a public isogeny pair leaks the kernel when #E is smooth over tiny primes (2⁶⁴·b with b<256).
- PARI's ffinit/ellweilpairing over GF(p²) beat the hand-rolled Sage path for 52×(factor-list) pairings.
