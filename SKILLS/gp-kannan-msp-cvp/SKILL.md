# PARI/GP Kannan CVP for multiple-subset-sum / 0-1 recovery

Use when a CTF needs exact integer recovery of a binary vector from integer equations (popcount-AND schemes, MSP/Unfairhamming style) and fpylll is unavailable — PARI 2.17 (gp64) alone suffices.

## Recipe (one block, n unknown bits, m equations)
1. A2 = 0/1 equation submatrix on free columns; rhs = c MINUS contributions of FIXED bits (e.g. known prefix). Never solve against raw c when columns are pinned.
2. `S=matsnf(A2,1); U_=S[1]; V_=S[2]; DD=S[3]` — rectangular SNF: pivots at `DD[j,nzcols[j]]` (nzcols = DD columns with nonzero column-sum). Particular: `y[nzcols[j]] = (U_*Mat(rhs~))[j,1]/DD[j,nzcols[j]]; m0p = Vec((V_*Mat(y~))[,1])`. Assert `max|A2*m0p-rhs|==0`.
3. `T0 = 1-2*m0p`; B = 2K (kernel basis); `Bred = qflllgram(B*B~,1)*B`; exact-Fraction Babai nearest-plane → Tred.
4. Kannan embedding rows `[(Bred|0); (Tred|beta)]`, **beta=1** → target norm² = n+1; `qfminim(G, n+1+8, 2)` — pad the bound (bound exactly λ can miss, float radius).
5. Decode with the ORIGINAL **T0**, not Tred: `m = m0p + (T0-pt)/2`, `pt = Vec(cf~*Ml)` (qfminim gives coefficient vectors). Parity, binary, then verify ALL equations.

## PARI 2.17 pitfalls (all hit once)
- `errcatch` REMOVED. `qfminim` returns `[N, maxnorm2, Mat]`; Mat columns = coefficient vectors, ± collapsed.
- `Mat(vec-of-vecs)` = matrix OF VECTORS → `matrix(r,c,i,j,expr)`.
- File parser: one statement per line (backslash continuation does NOT work); multi-line only inside `fn() = {...}`; nested fn defs → "embedded braces" error — helpers top-level, main flow in fn().
- Dot products: `vecsum(vector(n,j,a[j]*b[j]))` beats `a~*b` type traps.
- String paths: forward slashes (backslash escapes interpreted).

## Discipline
- TOY variant first: fake known block → encrypt → identical pipeline → must recover. This caught the Tred-vs-T0 reconstruction bug that cost a prior session.
- Never hardcode flag prefixes (SekaiCTF = SEKAI{...}); solve block 0 unconstrained and read bytes.
- SNF dominates runtime (~90s at 128x224); LLL-only basis fine when coset gap ≥ ~10 (beta=1 tightens radius).
- PARI 2.17: `grosstime` is a reset-VARIABLE (`grosstime=0` then read), NOT a function — `grosstime()` => "not a function". `write(file,str)` takes exactly 2 args (3rd => "too many arguments"). `qfminimbot`/`qflllpartial` REMOVED in 2.17; qflll flags have no deep-insertion/BKZ option — LLL is the ceiling.
- DIM CEILING (failproof_revenge @249): with LLL-only basis the enum bound vs GSO-profile decides cost. Wall statistic = count of ||b*_i||^2 <= bound on the Kannan basis (det(M)=det(lattice) so embedding inherits the profile): 104 levels below bound at dim 248 (spread ~1.184/level in norm^2) made radius-513 qfminim run >90min without return even on a guaranteed-solution TOY => enumeration COST wall, not coset emptiness. Measure with float GSO at realprecision>=120 (default 38 collapses: fake min 8e-5). At dim ~100 (321 original) LLL+qfminim solves in minutes.
- Bounded-MSB structure: in padded-with-random embeds (rand||secret||rand blocks), ONLY the secret-byte MSBs are droppable; do NOT assume prefixes or tail zeros anywhere — one correct 504-free setup for ALL blocks beats N wrong-coset variants.
- VALIDATE CONFIG BEFORE TRUSTING A NEGATIVE: a wall measured on a wrong coset (wrong rhs) is worthless. Re-derive rhs/A2 independently and assert A2*m0==rhs before reporting 'engine too weak' or any other negative.
